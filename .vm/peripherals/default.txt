# CC-OS VM peripheral list (used by run-local.ps1 -Peripherals <file>)

# One peripheral per line:   <name/side> <type> [options...]
#   types:   anything periphemu.create accepts (modem, monitor, speaker, drive,
#            printer, chest, energy, tank, debugger, ...)
#   options: disk=<id>                      drive: insert floppy disk <id>
#            <slot>=<item>[*<count>]        chest: put an item stack in a slot

#                                           extra argument (numbers converted)
#
# Sections pick which VM computers get the lines below them:
#   [all]  every PC (default before any section)
#   [main]  the first PC     [secondary]  the extra PCs (-Computers 2+)
#   [3]  only computer id 3  [2, 3]  computers 2 and 3
# '{id}' in a name becomes the computer's id (e.g. chest_{id}).
# '#' starts a comment.
